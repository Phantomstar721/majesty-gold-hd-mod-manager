# Majesty Mod Manager

Choose your Majesty Gold HD mods in one place, safely combine supported custom
guild mods, manage compatible quality-of-life improvements, and launch the
result through the runtime those mods need.

## What it does

- Finds mods and quests installed locally or through Steam Workshop
- Sorts content into Merge, Standard, Quests, and Quality of Life
- Enables compatible detected mods by default and remembers later choices
- Combines any selected set of manager-compatible CAM mods into one validated
  local package
- Keeps ordinary Standard mods independent and leaves downloaded quests alone
- Installs and removes ten compatible quality-of-life improvements
- Includes the Expanded Building Slots and Freestyle compatibility runtime
- Supports both Default Public `1.5.2.24` and beta2 `1.5.2.28`

Mods that cannot yet be combined safely are shown in red and cannot be
selected. The manager stops on an unknown conflict instead of silently letting
one mod overwrite another.

The original Custom Guild: Phantoms Haunt is recognized automatically. When it
is selected, the manager uses its included compatibility edition so the stock
Elf Guild remains available alongside the separate Phantom guild.

Current private-preview Merge support covers Custom Guild: Phantoms Haunt and
Custom Guild: Alchemist Lab. The merge process itself is package-driven and can
accept any number of mods that meet the published compatibility requirements.

## How to use it

1. Subscribe to this item and the Majesty mods you want.
2. Open this item's Workshop folder.
3. Keep the entire download together and run `Majesty Mod Manager.exe`.
4. Approve the Windows administrator prompt.
5. Install the two required helpers on the Quality of Life tab when prompted.
6. Review the automatically selected mods.
7. Choose **Prepare Selected Mods** when Merge mods are selected.
8. Choose **Launch Majesty**.

Always launch through the manager while using prepared Merge content.

The app is not code-signed, so Windows may show a SmartScreen warning. Use
**More info > Run anyway** only for the official Workshop or GitHub download.
The application is open source, and the upload includes its license notices
and SHA-256 file manifest.

The download contains no stock Majesty archives or extracted stock art. It
uses the copy of Majesty Gold HD already installed through Steam and leaves
subscribed source mods untouched.
