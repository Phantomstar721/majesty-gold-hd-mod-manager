Download `Majesty-Mod-Manager-v0.3.6.zip`, extract the complete folder, and run `Majesty Mod Manager.exe`. Keep the EXE beside its `_internal` folder.

What's changed:

- Repeat scans and Merge selections avoid unnecessary full-package work.
- Installed-package caching now follows declared mod content while ignoring unrelated media and Manager-generated output.
- Failed builds discard temporary data and recover the last completed Manager package when needed.
- Required game helpers use the same registry and installer path as the Quality of Life tab.
- Runtime injection now fails safely instead of waiting forever, and quest-board polling no longer floods the runtime log.
- Public source setup and release staging support ordinary Python, current Visual C++ tools, and custom dependency locations.

To update, close the manager and game before replacing the application files. Continue launching Majesty through the manager when using Merge mods.
