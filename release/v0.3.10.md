# Majesty Mod Manager 0.3.10 candidate

Corrects native support registration across repeated quest loads and recognizes
the equivalent stock SDK scripts used by GPL debugging mode. Normal and SDK
script paths retain the same conflict and load-order validation. The release
does not include the temporary first-fault diagnostic tracing.

Combine Standard and Merge mods with one preferred-mod choice per conflicting
pair. Safely compatible changes remain combined; Details provides additional
conflict information without requiring players to edit scripts.

Standard load-order preferences now appear together in one review window,
with expandable details. Contradictory choices can be corrected together before
saving. Shared sound definitions and audio records also use preferred-mod
choices instead of failing later during Prepare.

Building XML overrides now use the same preferred-mod choices. An existing
building supplied by a selected Standard mod does not need a new custom-building
declaration. Independent stock-relative fields combine; incompatible records
follow the player's preference. Original/expansion scope remains separate.

Retains the production three-version runtime and cache corrections from 0.3.9.
Supports shared damage contributions and native projectile interception across
all three executable profiles. Compatible executable patches are admitted by
checking the supported build and the consumed native code, not unrelated bytes.
Shipped matching GPL projects are discovered without requiring duplicate Source
rows in a manifest. Project-relative diagnostic filenames remain recognized.
Incompatible single-site reward observers use preferred-mod choices instead of
forcing notifications into a rewritten Standard function.
Corrects timed image relocation so coordinates and timing are not mistaken for
image references, and recognizes script decimals written without a leading zero.
Art composition also handles compact TILE/SPLT tables with sparse numeric TOC
IDs, preserving their references without treating their records as stock-slot
replacements. Existing positional art packages keep their lookup behavior.
Image set tables may retain their authored order even when their bodies are
stored in a different order. Tile placement accounts for relocated palettes,
preventing collisions between otherwise identical source tiles.

Corrects version-5 building animation art, including damage states. The Manager
now distinguishes frame tile references from coordinates and trailing animation
events, preventing shifted artwork and missing tiles after merging. Coordinates,
timing, and event data remain unchanged. Independent byte-preservation regression
checks now cover this layout alongside the existing timed-image checks.

Periodic spell damage integration preserves selected scripts' call arguments
and branches instead of requiring an exact stock damage statement. These are
generic composition rules, not exceptions for particular mods.

Close Majesty and the Manager before updating. Keep the complete application
folder together, then reopen the Manager and Prepare Again.

This candidate excludes private-hero attack APIs, checked placement,
paid-command extensions, and diagnostic tracing. Shared projectile lifetime
support is internal to interception. Human gameplay acceptance is separate from the
mandatory executable-fixture and native installation checks.
