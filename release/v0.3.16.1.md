# Majesty Mod Manager 0.3.16.1 (hotfix)

- Fixes false source/bytecode mismatch errors for Standard mods compiled from
  a source subfolder. A compiler project can record `Logic.gpl` while the mod
  manifest declares `GPL/Logic.gpl`; both identify the same registered source.
- Keeps the complete executable-byte comparison. Only filename fields proven
  by the existing compiler probe accept the additional relative spelling.
  Changed instructions, arguments, constants, strings and line numbers still
  fail validation.
- Adds regression coverage with the actual SDK compilers for Default Steam
  1.5.2.24, Steam beta2 1.5.2.28 and GOG 1.5.2.28.

Update the Manager and retry Prepare. Affected mod authors do not need to edit
or recompile otherwise matching packages. No extra compiler pass, scan or
game-time processing is added.
