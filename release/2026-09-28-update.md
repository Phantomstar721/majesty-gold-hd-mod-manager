# September 28 update

These notes cover the current source and staged Workshop update. They do not
announce a new downloadable GitHub release.

## Player-facing improvements

- Simpler conflict choices: each card shows the two mods and affected gameplay.
  Choose a preferred mod; open **Details** only when you want more explanation.
  Both mods remain enabled, and compatible changes are retained.
- Improved preservation of selected Standard-mod scripts when preparing shared
  features, with separate handling for original and expansion quests.
- Compatibility improvements for healing-potion changes that move consumption
  into a separate helper function.
- Corrections for cross-version content, inventory-only actions appearing in
  the Spells panel after loading a save, and a runtime startup failure.

## For mod authors

A Standard package containing multiple variants can now share one set of hero
quest-participation declarations across an explicit `mod_ids` list. Existing
single-ID definitions remain supported. Each selected variant still uses its
own scripts; the list does not enable sibling variants or automatically discover
custom hero logic. See the [format and example](../docs/standard-script-providers.md#shared-declarations-for-standard-variants).

## Updating

Close Majesty and the Manager before replacing the application. Keep the entire
application folder together, including `_internal`. After updating the Manager
and your mods, reopen it, **Rescan Content**, then **Prepare Selected Mods** or
**Prepare Again** before launching.

To revisit saved conflict choices, select **Review mod preferences** before
Prepare. See [choosing preferred mods](../docs/script-conflict-review.md).
