Download `Majesty-Mod-Manager-v0.3.5.zip`, extract the complete folder, and run `Majesty Mod Manager.exe`. Keep the EXE beside its `_internal` folder.

What's changed:

- Custom building open/close controls are now initialized on the first building-panel presentation.
- Combined parent panels containing reward, occupant, and toggle features retain their normal later setup, event, and command refresh behavior.

To update, close the manager and game before replacing the application files. Continue launching Majesty through the manager when using Merge mods.
