# Majesty Mod Manager 0.3.12 (beta)

- Classic Launch runs selected Standard mods without preparing a merge.
- Save up to five named profiles with mod choices, game installation, launch mode and expansion-content setting.
- The global expansion-content toggle clearly includes original Majesty quests.
- New and Updated pills and gold tab indicators highlight changed installed content.
- History beneath the Manager version shows brief patch summaries. Its gold dot marks a changed Manager version until the next scan or app session.
- Fixes Use selected profile so saved setups load and restore their launch and expansion-content settings correctly.

Supports Steam Default 1.5.2.24, Steam beta2 1.5.2.28 and GOG 1.5.2.28.
Close Majesty and the Manager before updating. Keep the full application folder together.
