# Majesty Mod Manager 0.3.16 (beta)

- Lets authors explicitly choose Merge for native panel packages using
  `"merge": true` in a schema-3 definition, including packages that replace
  existing windows without adding a custom building.
- Keeps independently loadable Window Engine packages in Standard by default.
  Merge opt-in retains normal source, dataset and resource-conflict validation.
- Uses the existing three-version Window Engine integration and preferred-mod
  choices; adds no new runtime hooks or load-order override.

Authors using the new field require Manager 0.3.16 or newer. Existing package
definitions remain supported. Rescan Content after updating a definition, then
review the Merge selections and Prepare normally.

Supports Default Steam 1.5.2.24, Steam beta2 1.5.2.28 and GOG 1.5.2.28 through
the existing guarded engine integration. This update does not require
reinstalling the optional engine patches or starting a new quest.
