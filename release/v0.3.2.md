Download `Majesty-Mod-Manager-v0.3.2.zip`, extract the complete folder, and run `Majesty Mod Manager.exe`. Keep the EXE beside its `_internal` folder.

What's changed:

- Custom panels now work at lower resolutions such as 1024x768, where a subpanel replaces the main building panel.
- Fixed custom-panel navigation and reopening actions after viewing a building's Visitors list.
- Added support for compatible mods that provide actions on building occupants.

To update, close the manager and game before replacing the application files. Continue launching Majesty through the manager when using Merge mods.
