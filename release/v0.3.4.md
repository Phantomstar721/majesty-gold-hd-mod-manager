Download `Majesty-Mod-Manager-v0.3.4.zip`, extract the complete folder, and run `Majesty Mod Manager.exe`. Keep the EXE beside its `_internal` folder.

What's changed:

- Fixed a false `can't combine` result for schema-v3 mods that use the stock-derived building open/close toggle.
- Catalog scanning and Prepare Package now carry the same manager-owned toggle metadata used by final composition.

To update, close the manager and game before replacing the application files. Continue launching Majesty through the manager when using Merge mods.
