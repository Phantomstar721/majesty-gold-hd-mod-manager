Download `Majesty-Mod-Manager-v0.3.3.zip`, extract the complete folder, and run `Majesty Mod Manager.exe`. Keep the EXE beside its `_internal` folder.

What's changed:

- Added safe, reusable support for custom building open/close controls based on Majesty's stock Embassy behavior.
- Added deterministic extension points for custom hero purchases after stock equipment and Magic Bazaar checks.
- Expanded the schema-v3 authoring guide and validation so compatible mods can declare these behaviors without a manager-specific hardcoded patch.

To update, close the manager and game before replacing the application files. Continue launching Majesty through the manager when using Merge mods.
