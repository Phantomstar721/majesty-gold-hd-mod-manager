# Majesty Mod Manager 0.3.13 (beta)

- Adds two independent optional Quality of Life patches: Custom Building Panels
  and Scripted Ground Actions. Both rows credit mikmak300.
- Explains selected content's detected or declared patch requirements before
  launch. Selecting content never installs these patches automatically.
- Supports native engine content as Standard mods without converting it to
  Manager-only packaging. Existing Merge, Standard, Classic Launch and named
  profile behavior is retained.
- Preserves typed panel references when composing supported resources.
- Corrects the research callback return value so completed research can retire
  its stock order instead of being called again with an empty research ID.

Version-specific installers and native contracts cover Steam Default 1.5.2.24,
Steam beta2 1.5.2.28 and GOG 1.5.2.28. Automated fixture coverage is separate
from live acceptance; the reported successful alpha playtest does not establish
live testing of every build.

Close Majesty before installing or removing either patch. Updating the Manager
does not prepare or replace your merged profile. Both native patches remain
optional and are installed only by an explicit user action in Quality of Life.
