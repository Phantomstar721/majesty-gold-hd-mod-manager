# Majesty Mod Manager 0.3.9

- Fixes a launch failure affecting research and movement integrations on
  default Steam 1.5.2.24 and GOG 1.5.2.28. Steam beta2 remains supported.
- Restores missing expansion artwork required by merged descriptions without
  replacing custom artwork.
- Refreshes cached compatibility results when the Manager, game version or
  relevant stock files change.
- Tightens script-merge checks for expressions that modify values.

Close Majesty and the Manager before replacing the complete application folder.
Reopen the Manager and choose Prepare Again before launching.

Development-only features are not included in this release.
