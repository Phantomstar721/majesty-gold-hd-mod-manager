# Majesty Mod Manager 0.3.15 (beta)

- Reduces repeated work in the native unit searches used by AI and quests.
  Busy games may benefit most; the gain depends on the workload. This uses
  existing searches and does not add a background scanner.
- Supports the optimization on Default Steam 1.5.2.24, Steam beta2 1.5.2.28
  and GOG 1.5.2.28. All three executable fixtures are required by verification.
- Preserves stock temporary-reference cleanup when search operations raise an
  error, with native fault, unwind and recovery coverage.
- Preserves bounded support-history files during packaged-file verification
  while retaining checks for changed code and resources.

Close Majesty and the Manager before updating, then launch normally. Existing
saves and prepared profiles can be used; this update does not require Prepare,
new mod declarations or reinstalling optional patches. Comparison tracing is
not enabled in this release.

The unit-search optimization was contributed by Veligon in PR #2. GOG support,
strict version parity and native error-lifetime verification are included in
this integration. Offline native verification covers all three profiles; it is
separate from gameplay acceptance and is not a universal performance guarantee.
