# Majesty Mod Manager 0.3.18 beta

- Choose which selected Merge mod supplies an overlapping window layout or its text. The Manager reuses saved preferences and validates the chosen layout before preparing it.
- Merge package authors can declare which windows they replace in a named package using `resource_replacements` in schema 3.
- Includes the shared timer fix for teleport spells, items, and other delayed movement abilities from 0.3.17.1.

Supports Default Steam 1.5.2.24, Steam beta2 1.5.2.28, and GOG 1.5.2.28.

Extract the full archive and launch `Majesty Mod Manager.exe` from the extracted folder.
