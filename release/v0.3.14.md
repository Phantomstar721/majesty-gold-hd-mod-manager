# Majesty Mod Manager 0.3.14 (beta)

- Combines supported reward eligibility, incentives and priority changes. Matching
  original scripts can be recognized without requiring an author-side rewrite.
  Unsupported overlaps still use the player's preferred mod.
- Lets Custom Building Panels present registered panels while the existing
  handlers continue to own recruitment, research, spells, prices and cleanup.
- Detects the actual installed optional-patch revision and offers an explicit
  upgrade when selected content needs a newer one. Native-only panel content
  remains supported.
- Fixes scanning and Prepare for source-backed Standard-only combinations.
- Leaves native language and quest XML with its original package rather than
  treating it as a building-only XML document.
- Completes shared timed-effect cleanup before notifying its owner, keeping
  callbacks that start or cancel another effect from using stale outer state.

Close the Manager before updating. Close Majesty before installing an optional
patch update, then Prepare your selected setup again. The Manager update does
not rebuild a saved profile or install an optional patch automatically.

Supported executable profiles remain Default Steam 1.5.2.24, Steam beta2
1.5.2.28 and GOG 1.5.2.28. Automated source, compiler, native and startup
coverage is distinct from player gameplay and save/load acceptance. The accepted
combined alpha playtest does not establish gameplay acceptance on every build.
