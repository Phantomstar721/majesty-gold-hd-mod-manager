# Majesty Mod Manager 0.3.17 (beta)

- Fixes false source/bytecode mismatches when a Standard mod was compiled from
  a source subfolder. Compiler-proven debug filenames may use project-relative
  paths; instructions, arguments, constants, strings and line numbers still
  have to match.
- Preserves additional mod eligibility checks when composing shared reward and
  completion notifications, without observing separate unpaid branches.
- Keeps completion notifications when mods mute the stock sound or wrap the
  full reward transaction in another eligibility check. Target validation
  follows the branch that can reach the notification.
- Preserves private inventory exclusions when a mod keeps the stock death-drop
  branch but changes which stock items it excludes.
- Shows conflict warnings for selected mods and excludes previously prepared
  Manager output from conflict checks.
- Keeps original-game and expansion-only mods independent in conflict checks.
  Shared locale containers do not count as overlapping descriptions.

- Adds independent **Borderless Window** and **Confine Cursor to Game Window**
  controls in Quality of Life, off by default and remembered per game install.
- Uses Majesty's native borderless window mode at the selected resolution.
  Exclusive fullscreen keeps its usual behavior.
- Adds **Ctrl+Shift+F11** to release/reconfine the cursor while the windowed game
  is focused. Focus loss, minimization and closing release it. A conflicting
  shortcut leaves confinement off.
- Applies to Manager launches, including Classic Launch, without Prepare or
  changes to MajXPrefs. Existing mods need no declarations or script changes.
- Coordinates GOG's existing cursor owner rather than adding competing clipping.

Supported profiles: Default Steam 1.5.2.24, Steam beta2 1.5.2.28, GOG 1.5.2.28.
The native window/cursor boundaries are guarded separately for each build.
Offline fixture verification and in-game acceptance are recorded separately.
