# Completed-stage action gating

The alpha child spell row used the raw building descriptor tier. That descriptor
already names the next tier while its upgrade is under construction. The compact
toolbar already used the completed tier, leaving two routes to the same paid
action with different admission rules.

`CompletedBuildingLevel` retains the existing stock arithmetic: raw tier minus
one when CurrentStageBuilt is zero. `BuildingActionMeetsLevel` also requires
FirstStageBuilt. Sovereign row presentation, visual descriptor eligibility,
target-mode entry, queued source admission and toolbar admission now share it.
AP99 research continues using its distinct raw-tier/prerequisite contract.
Payment still belongs to the existing stock executor; the queued action rejects
an unfinished source before reaching it. No timer or per-unit scan is added.

A locked sovereign row no longer receives an extra native single-row preparation
after stock whole-panel setup. Native preparation changes a presentation count;
a later hide is not necessarily its inverse. The original setup order remains.
This addresses the established redundant preparation path; loaded-game first-open
visual acceptance remains required, rather than assuming every blank outline has
the same cause.
