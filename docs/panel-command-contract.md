# Immediate building commands

Available in Manager 0.3.11 across the three supported executable profiles.

A `stock.ap10-ap69-secondary-panel.v1` declaration may contain `commands`:

```json
"commands": [{"control_id": 31904, "callback_symbol": "TryBuildingAction"}]
```

The package owns `function TryBuildingAction(agent Building, boolean Commit)
is boolean`. False quotes without mutation; True revalidates and performs the
whole transaction without yielding. The provider owns all payment and effects.
Native price is always zero. This does not create a research completion bit or
cooldown. Missing optional providers return False through the typed dispatch.

MMCR27 carries generated quote, commit and owner adapters. Controls remain
visible when unavailable. The page's tier/employment/eligibility gates apply
again at queue delivery. The immutable packet retains command, building handle,
initiating player number and zero price; closing the panel cannot redirect it.
Changed owner, missing building and nonzero native price reject delivery.
Every valid click is a transaction; the provider must reject obsolete quotes.

Stock reference: the existing MX05 command21 branch resolves its subject,
checks its owner treasury, subtracts the packet price, invokes a one-agent GPL
function and destroys its evaluator. The adapter supplies the source building
as subject and generated commit as function, preserving that sequence. Existing
PairedOccupantProfiles.h windows guard the complete branch, lookup and common
continuation for Public, beta2 and GOG, without enabling paired arguments.
The existing panel setup/event refresh invokes quote; no unit scan is added.

Native fixtures cover closed panels, invalid handles, changed owners, and
rejection of a second native payment. Offline profile fixtures pin all three
exact executable images. These checks are not in-game acceptance.

This immediate contract does not establish saved delayed-action lifetime.
Purge remains separate until that evidence is complete.
